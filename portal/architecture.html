Phone & laptop

Access the portal on your home network or through WireGuard when away. The map is visible without an admin session.

Learn about private VPN access

WireGuard / wg-easy

Encrypted remote access. The wg-easy administration web page is bound to the Pi's loopback port and requires an SSH tunnel; it is not a public portal destination.

SSH-tunnel-only management · no direct web link

HomeAway portal

This read-only service status page and the embedded, shared Grafana view. It cannot administer DNS, VPN, user accounts, PCs or Windows fans.

Open overview

Pi-hole

DNS filtering and private hostname resolution for devices using your home's DNS. This portal may probe DNS responsiveness but cannot reconfigure it.

Open Pi-hole console

Authelia, LLDAP & HomeAway Control

Private HTTPS sign-in and current household permissions protect PC controls and the admin-only computer/user management pages. LLDAP administration itself remains SSH-tunnel-only.

Open authenticated controls

pcctl host agent

Restricted Pi-side power commands and a separate non-root inventory writer. The web interface sends only allowlisted requests; no generic shell or Docker control is exposed.

Admin and power actions require authentication

Windows PC

Registered desktop computers can accept supervised power requests. A reachable SSH port is not proof that the PC is healthy or that a power action completed.

Open computer controls

SensorDash

Windows owns sensor sampling, local PWM curves, fan association, and tray status. HomeAway does not duplicate fan controls; the collector exports observational telemetry.

See read-only metrics

Telemetry ingest

An authenticated TLS receiver accepts SensorDash measurements and forwards them to the internal metrics store. It has no browser control interface.

Write-only sensor intake · no admin link

VictoriaMetrics

Internal-only time-series history. It does not publish its query API on a LAN port; Grafana reads from it and renders dashboards.

Explore Grafana

Grafana

Dashboards for cooling observations, Pi health, DNS/VPN summaries and history. Editing and administration belong to Grafana, not the HomeAway portal.
