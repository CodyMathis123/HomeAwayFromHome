YOUR COMPUTERS

Power and presence.

Wake your computers or request Windows power actions. The PC must be configured for SSH and Wake-on-LAN. Status checks SSH reachability only; power requests are not confirmation that Windows completed the action.

Computer management

Existing machines remain active. New entries start as drafts and cannot be controlled until their Windows setup and SSH trust are verified in a later enrollment step.

Prepare a new computer · guided draft setup

Step 1: save its network identity as an inactive draft. Step 2: follow the Windows pairing checklist on the draft card. Step 3: verify pinned SSH trust before activation. Existing computer IDs and power controls are unaffected.

Disabled and archived computers

Disabled computers are removed from the active power-control inventory. Their last verified configuration is retained privately. Restoring one requires a fresh authenticated SSH identity check.
